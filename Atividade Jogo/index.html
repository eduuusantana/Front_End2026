1
Decomponha em componentes +

Quebre a tela em componentes reutilizáveis:

  • Grid — o tabuleiro (6 linhas × 5 letras)
  • Tile — cada quadradinho com cor de feedback
  • Keyboard — teclado virtual

Regra: se algo se repete na tela, é um componente.

2
Estado central com useState +

Toda a lógica do jogo fica num custom hook:

const [guesses, setGuesses] = useState([])
const [current, setCurrent] = useState('')

function submitGuess() {
  if (current.length !== 5) return
  setGuesses([...guesses, current])
  setCurrent('')
}
3
Tile recebe cor via props +

O Tile é puro — só exibe o que recebe:

function Tile({ letter, status }) {
  return <div className={`tile tile--${status}`}>{letter}</div>
}
1
Sem limite de tentativas +

O jogador digita palavras e recebe uma distância semântica — quanto menor, mais perto da resposta. As tentativas ficam ordenadas por proximidade.

Buscar a distância com fetch + 
async function handleGuess() {
  const res = await fetch(`/api/tip/${input}`)
  const data = await res.json()
  setGuesses(g => [...g, data].sort((a,b) => a.distance - b.distance))
}
1
Estado complexo → useReducer +

16 palavras formam 4 grupos secretos. O jogador seleciona 4 por vez. Quando várias partes do estado mudam juntas, useReducer organiza melhor que vários useState.

Regra: ação única, várias mudanças de estado → useReducer.

2
Verificando o grupo no reducer + 
function handleSubmit(state) {
  const ids = state.selected.map(w => w.groupId)
  const acertou = ids.every(id => id === ids[0])
  return acertou
    ? { ...state, solved: [...state.solved, ids[0]], selected: [] }
    : { ...state, mistakes: state.mistakes + 1, selected: [] }
}
